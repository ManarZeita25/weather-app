# 🌦️ Weather App

A modern weather dashboard built with React + TypeScript that provides real-time weather updates for your favorite cities using the Open-Meteo API.

## 🚀 Live Demo

🌍 Live Website: [https://weather-app-mu-ruddy-93.vercel.app/](https://weather-app-nine-beige-16.vercel.app/)

---

## ✨ Features

- 🔍 Search for cities worldwide
- 🌡️ Real-time weather data
- 💨 Wind speed information
- 🔄 Auto refresh every 60 seconds
- ➕ Add multiple cities
- ❌ Remove cities
- 🎨 Responsive modern UI with Tailwind CSS
- ⚡ Fast performance with Vite

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Open-Meteo API
- Open-Meteo Geocoding API
